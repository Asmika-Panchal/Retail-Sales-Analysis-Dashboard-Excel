# 📊 Retail Sales Analysis Dashboard (Excel)

## 📌 Project
Interactive Sales Dashboard created using Microsoft Excel to analyze sales data using Pivot Tables, Charts, Slicers, KPI cards, and VBA Macros.

## 🎯 Features
- Pivot Tables for data summary
- Pivot Charts for visualization
- Slicers for filtering
- KPI Cards (Total Sales, Top Region, Top Product, etc.)
- Target Hit % calculation
- Reset Filters Macro
- Summary Report Macro

## 📂 Dataset Columns
Date, Month, Region, Category, Product, Sales, Quantity, Target, Target Hit %, Away from Target %

## 🛠 Tools Used
- Microsoft Excel
- Pivot Table
- Pivot Chart
- Slicer
- Excel Formulas
- VBA Macro

## 📊 Dashboard Includes
- Sales by Month chart
- Sales by Region chart
- Sales by Category chart
- Sales by Product chart
- Sales by Salesperson chart
- KPI Summary Cards

## ▶️ How to Use
1. Open the Excel file  
2. Use slicers to filter data  
3. Click Reset button to clear filters  
4. Click Summary Report to generate report
